Market-Entry Analysis

MySQL · SQL · Tableau

Queried a 9-table marketplace database to decide whether an online tech retailer should partner with a Brazilian platform. Found that ~93% of orders arrive on time and tech makes up ~14% of revenue; recommended signing the deal and presented the results in a Tableau dashboard.

Playlist Clustering for a Music Startup

Python · Scikit-learn · Spotify API

Built a K-Means model that grouped 5,000+ Spotify songs into 34 playlists of 50–250 songs each, to test whether machine learning can replace manual curation. Cleaned the data (duplicates, outliers, feature selection), compared 5 scaling methods and reduced 9 audio features with PCA while keeping 95% of the variance. Published the playlists via the Spotify Web API and explained the limits to a non-technical audience: the model makes good first drafts, but an expert should still review them.

Automated Cloud Data Pipeline for E-Scooter Demand Analysis

Python · MySQL · BeautifulSoup · REST APIs · Google Cloud

Built an end-to-end ETL pipeline that scrapes city data from Wikipedia, pulls weather forecasts and flight schedules from REST APIs, and loads everything into a 5-table MySQL database on Google Cloud SQL. Deployed it as Cloud Run functions triggered by Cloud Scheduler, with duplicate-free re-runs and credentials stored in Secret Manager. Handled missing fields, empty responses, rate limits and timezone differences, and debugged production failures from Cloud Run logs.

Discount Strategy Analysis

Python · Pandas

Cleaned three raw sales tables (malformed prices, 8,700+ duplicate rows) and tested whether discounts pay off. Sales stop rising above a 20% discount, and budget items get the deepest cuts but bring in only 5.9% of revenue; recommended capping discounts at 20% and shifting them to high-end products.

A/B Test of Homepage Buttons

Python · SciPy · Statistics

Compared four button designs across ~100,000 homepage visits using a chi-square test with Bonferroni-corrected pairwise tests. White buttons clearly beat red ones (2.0–2.1% vs. 0.8–1.1% click-through rate); the two white versions showed no significant difference.
